VELVET PASSPORT - CHOOSE YOUR NIGHT

Open index.html in a browser.

Features:
- 12 date nights selected by craving/mood, not month
- filters for Steak, Truffle, Ramen, Pasta + Noodles, Dares, After Dark, Cozy, Fancy, Shareable
- dedicated Sapporo ramen night
- varied floral styling across every night
- interactive Dare Deck on every night
- serving selector for 2 / 4 / 6 / 8 (defaults to 2)
- dynamically scaled recipe ingredients and grocery checklists
- persistent grocery checkboxes
- surprise picker respects the currently selected filter
- mobile responsive + print/PDF styling

Deploy to Vercel as a static site; no build command required.
